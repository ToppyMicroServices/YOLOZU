Stable lane

A 30-minute path to a checked report

This path is CPU-only and begins with generated proof artifacts, so the dataset and prediction paths come from evidence rather than memory.

Proof → visible demo → validate → evaluate

0–5 minutes

Install and prove the stable lane

python3 -m pip install -U yolozu
yolozu doctor --proof --output reports/dod_cpu_smoke/doctor.json --proof-dir reports/dod_cpu_smoke/doctor_proof

Expected: A CPU-only proof report, known predictions, toy dataset, and pinned mAP result under reports/dod_cpu_smoke/doctor_proof/.

5–10 minutes

Create visible evaluation evidence

yolozu demo instance-seg --inference none --run-dir reports/dod_cpu_smoke/demo_instance_seg --progress

Expected: instance_seg_demo_report.json and PNG overlays under reports/dod_cpu_smoke/demo_instance_seg/.

10–18 minutes

Resolve the proof artifacts

PROOF=reports/dod_cpu_smoke/doctor_proof/proof_report.json
DATASET=$(python3 -c 'import json,sys; print(json.load(open(sys.argv[1]))["artifacts"]["dataset"])' "$PROOF")
PREDICTIONS=$(python3 -c 'import json,sys; print(json.load(open(sys.argv[1]))["artifacts"]["predictions"])' "$PROOF")

Expected: DATASET and PREDICTIONS point to the files recorded by the proof report; no path is guessed.

18–23 minutes

Validate both sides of the interface

yolozu validate dataset "$DATASET" --split val2017 --strict
yolozu validate predictions "$PREDICTIONS" --strict

Expected: Both strict validators exit successfully before evaluation.

23–27 minutes

Run the pinned evaluation

yolozu eval-coco --dataset "$DATASET" --split val2017 --predictions "$PREDICTIONS" --dry-run --output reports/dod_cpu_smoke/eval_coco_dry_run.json

Expected: A checked detection evaluation report at reports/dod_cpu_smoke/eval_coco_dry_run.json.

27–30 minutes

Read before comparing

Expected: Confirm task, dataset/split, prediction source, export settings, protocol identity, metric family, and any skipped lane before comparing two reports.

I have a checked report Something failed

Canonical procedure: CPU-only DoD.

Continue to the two-hour path

  1. Complete the 30-minute stable path.
  2. Export or import predictions from an external stack through a checked bridge.
  3. Run a CPU-only evaluation with the same dataset, split, and fixed protocol.
  4. Compare two wrapped prediction artifacts and their reports.
  5. Fill out docs/evaluation_protocol_template.md for the run.
  6. Choose stable evaluation, backend parity, or a Research lane from evidence—not from a missing feature assumption.

Use the evaluation protocol template before comparing artifacts.
