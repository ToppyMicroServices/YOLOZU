## Clone automation caveat

The clone series remains unsuitable as human adoption evidence. GitHub reported
383 clones but only 3 repository views across the rolling window. Three days
also had a clone-to-unique ratio above five:

| UTC date | Clones | Unique cloners |
|---|---:|---:|
| 2026-10-19 | 14 | 2 |
| 2026-10-25 | 15 | 2 |
| 2026-10-26 | 239 | 45 |

These observations meet the documented automation-sensitive rule. The exact
mix of CI, mirrors, scanners, and other sources is unknown. A GitHub unique
cloner is not necessarily a person, so human adoption from clones remains
`unknown`, not 84.
