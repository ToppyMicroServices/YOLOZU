## Clone automation caveat

The clone series remains unsuitable as human adoption evidence. GitHub reported
582 clones but only one repository view across the rolling window, and one day
had a clone-to-unique ratio above five:

| UTC date | Clones | Unique cloners |
|---|---:|---:|
| 2026-08-04 | 71 | 23 |
| 2026-08-10 | 72 | 57 |
| 2026-08-13 | 371 | 333 |
| 2026-08-17 | 13 | 2 |

The 2026-08-17 ratio and the total clone volume relative to repository views
meet the documented automation-sensitive rule. The exact mix of CI, mirrors,
scanners, and other sources is unknown. A GitHub unique cloner is not
necessarily a person, so human adoption from clones remains `unknown`, not 423.
