# External finetune smoke templates

Framework-specific templates used by `tools/run_external_finetune_smoke.py`:

- `ultralytics_yolov8n_finetune_smoke.yaml`
- `mmdetection_finetune_smoke.py`
- `detectron2_finetune_smoke.yaml`
- `rtdetr_pose_finetune_smoke.yaml`

These templates are intentionally small and prioritize fast smoke runs.
